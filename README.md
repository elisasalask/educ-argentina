# Education in Argentina

API-209 final exercise: evidence for a Model Teacher Statute in Argentina.

Open `educ-argentina.Rproj` in RStudio. Code, comments, and project documentation are in English. Original source filenames and variable names are preserved.

## Get the data

Run this in the RStudio Console from the project:

```r
source("R/00_download_data.R")
```

The script reads `data/download_manifest.csv`, downloads missing files into `data/raw/`, and skips existing files. It requires no extra R packages. Large files can take time. To download one source:

```r
options(education.datasets = "aprender")
source("R/00_download_data.R")
```

Use `options(education.datasets = NULL)` to restore all datasets. Download failures are recorded in `data/last_download_run.csv`; rerun to retry. Existing files are skipped, so remove a damaged file before retrying it.

## Project folders

- `R/`: shared R scripts.
- `data/raw/`: original datasets and documents; do not edit these files.
- `data/processed/`: cleaned files generated by analysis scripts.
- `data/download_manifest.csv`: selected source files and download links.
- `data/course_file_inventory.csv`: broader course Drive inventory, including optional historical files and instructor analysis outputs. Discovery was limited to six folder levels; it is not an exhaustive archive.
- `data/download_status.csv`: initial download results, sizes, and SHA-256 checksums.
- `docs/data_sources.md`: coverage, source links, and issues to check.
- `0.Analysis.R`: existing team script.

## Working together

Pull before editing, coordinate changes to shared scripts, then commit and push code and documentation. Raw and processed datasets are excluded by `.gitignore`: teammates download their own copies using the same script. Several files exceed GitHub's normal per-file size limit. Do not force-add the raw data.

Use project-relative paths, such as `data/raw/aprender/2023/Aprender_2023_Docente_6grado_Primaria_Censal.csv`. Read CSVs after checking delimiter, encoding, missing values, and variable definitions. Use `haven::read_dta()` for Stata data and `readxl::read_excel()` for salary workbooks (install those packages if needed).

The download setup does not clean data, verify the instructor-provided labels against questionnaires, or establish valid links across sources. PISA and ERCE analyses require appropriate survey weights and plausible values where relevant.

## Interactive context page

An English research-context explorer connects the four teaching-career dimensions to provincial primary-education context and reference salaries. The site is private to its owner:

https://argentina-teaching-careers-context.politecourt.chatgpt.site

`R/01_build_context_data.R` generates the aggregate datasets used by the page. Run it from this RStudio project after installing `readxl` and `jsonlite` if needed. It writes aggregates to the sibling `teaching-careers-context/dist/` directory; it does not rebuild or deploy the full website. School-level identifiers and individual questionnaire records are not included in website assets. The statutory comparison remains a research framework, not a completed legal coding exercise.
